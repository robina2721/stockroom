Fill photos & sizes automatically

Your store already publishes every product photo and variant (size/color) publicly — we just can't read it from this page directly. A short one-time script fixes that:
Open addisoutfits.com in Chrome → press F12 → click the Console tab → paste the script → press Enter. It downloads a file called addisoutfits-catalog.json.
Close this box, click Fill photos & sizes above, and pick that downloaded file. Every item whose variant ID matches gets its photo and size/color filled in automatically — no per-item copying.

Sync results

Each line shows what was found, separated by " | ". A row needs all three: title, variant ID, and a plain number for quantity. Common causes: a blank Variant Id or Qty cell, or a Qty cell containing text (like "n/a" or "2 pairs") instead of just a number.

Sync across devices via GitHub

This stores your inventory as a file in your GitHub repo, so your phone, laptop, or any device pulls the same data. It needs a personal access token — a password-like key scoped to just this one repo. Keep it private; anyone with it can edit this repo.
Once you connect once and save, anyone who simply opens your site link will automatically see this same live data too — read-only, with no token of their own needed. Only you, with the token, can push changes.
This file doesn't need to exist yet — it's created automatically on first sync.
How to get one: on GitHub, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → "Generate new token". Set Repository access to "Only select repositories" and choose this repo. Under Permissions → Repository permissions, set Contents to Read and write. Copy the token (starts with github_pat_) and paste it here — GitHub only shows it once.
